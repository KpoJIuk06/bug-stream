# Changelog

## 0.4.0 — first public release
- Chrome extension 0.4.0: tab video, screenshot, instant replay (last 2 minutes) with console, network and actions;
  English / Russian / Azerbaijani; sign-in with password or e-mail code; searchable project picker; "Create an issue in Jira".
- Server: reports with player and DevTools-like tabs, comments, history; reports grouped by project; dashboard.
- Jira Cloud: project sync and linking, personal tokens, issue types with a safe fallback, issue status sync (label `bugstream`).
- Slack channel posts and direct messages.
- Sign-in methods: password, Active Directory / LDAP, one-time e-mail code; SMTP settings, invitations, password reset.
- Roles & permissions, environments, public share links, audit log, admin panel.
- Site widget 0.2.0.
- Works on Windows, macOS and Linux: the extension popup shows the real shortcuts (⌥⇧R on macOS), `init-env.sh` and
  `pack-extension.ps1` (PowerShell 7) run on macOS, MDM policy for Macs is generated next to the GPO one.
